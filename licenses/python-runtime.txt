Slot/Apps/python: the Python runtime Slot puts on the TrimUI Brick card for HOME -> Apps.

Slot does not include any app; this runtime lets an app the player installed (GrainBrick, see
grainbrick-not-included.txt) run on the Brick, which has no Python of its own. It is built by
brick/python-runtime/build.sh from the pinned downloads in brick/python-runtime/sources.txt.
Parts not needed on the Brick are left out (test suite, IDLE, Tk, pip, dbm and pygame's
examples, tests and docs).

SoundTouch 2.3.2 (lib/compat/libSoundTouch.so.1)
  GNU LGPL 2.1 (pygame-LGPL-2.1.txt is the same text). Source, built unchanged with its default
  configuration: https://codeberg.org/soundtouch/soundtouch/archive/2.3.2.tar.gz
  GrainBrick's own copy of this library needs a newer system than the Brick's (glibc 2.38);
  run-app.sh puts this build ahead of it, as GrainBrick's SoundTouch notice provides for. You may
  replace it with your own build of SoundTouch: put it at lib/compat/libSoundTouch.so.1.
